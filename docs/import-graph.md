# The import graph

Every value import between the project's modules: `A --> B` means `A.ts`
imports something from `B.ts` that survives to runtime. Type-only imports are
left out — they bind no module together — and so are the test suites.

`orchestrator/testing/import-graph.ts`; the layering it should show is
[The layers](architecture.md).
