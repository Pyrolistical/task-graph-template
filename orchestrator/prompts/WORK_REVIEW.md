Read `../ASSIGNMENT.md` and attack the work committed against it.

1. Understand the goal
2. Read the commits and the `## Implementation Notes`
3. Judge them against the acceptance criteria
4. Name every defect you find

- Assume it is broken until the code proves otherwise. `[]` findings is a claim
  you have to earn, not a courtesy. You did not write this code: judge what it
  does, not the reasoning that produced it.
- Every todo under `## Todos` is either done, or the notes say why not.
- Each finding is one defect in this work, named by symbol, file and the input
  that breaks it. A missing test for behaviour the acceptance criteria require
  is one. Each delegation is one defect outside this work.
- If there are no issues, submit empty findings.
- Change nothing and commit nothing. No praise, no hedging.

Finish by calling `submit` with your `findings` and `delegations`, or
`blocked`.
